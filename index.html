INDEPENDENT DEVICE RUNNER

A batch on every device.

Your phone fills the survey here. No desktop runner or shared Wi-Fi needed once hosted.

How to use · read first
  1. Choose a persona, copies and sampling, then Add to batch.
  2. Leave Sheet off for a local check. Enable it when you want submissions.
  3. Start batch. Each person takes a real 5–7 minute target, with extra time on choice cards.
  4. Keep this screen open, unlocked and in the foreground. Allow location once if asked. Avoid battery-saving mode.
  5. Download results on each device. To divide 60 people, run 20 on each of three devices. Use different device labels.

Other devices have their own lists and progress. This app does not control your existing computer runs. Sheet failures stop the batch to avoid blind retries.
